# kifumate UIモック

UI/UXを決めるための検討用モックです。決まったものは実装見本として使います。
特定のアプリ開発技術には依存しない、素のHTML/CSS/JavaScriptで作っています。

## いまあるもの

| ファイル | 内容 |
| --- | --- |
| `src/analysis-variants.html` | 解析画面のデザイン3案（A 和モダン／B 明るいミニマル／C ポップ）の比較ページ |
| `data/sample-game.json` | サンプル棋譜と各局面の解析データ |
| `tools/gen_sample_game.py` | サンプルデータの生成スクリプト（Python + cshogi） |
| `tools/build.py` | `src` にデータを埋め込んで `dist` に書き出す |
| `dist/*.standalone.html` | そのままブラウザで開ける単体ファイル |
| `dist/*.html` | 公開用（外枠なし。公開時に `<html>` などが付く） |

## 見かた

`dist/analysis-variants.standalone.html` をブラウザで開きます。
幅の広い画面では3案が横に並び、狭い画面では1案ずつ切り替えて表示します。
スマホで開くと、枠なしで画面いっぱいに表示されます。

## 作り直しかた

```
python3 mock/tools/build.py
```

サンプルデータから作り直す場合は、先に `mock/tools/gen_sample_game.py` で自己対局・解析・検証を行います（`pip install cshogi` が必要。手順はスクリプト冒頭の「使い方」を参照）。時間制限つきの探索なので、再実行しても完全に同じデータにはなりません。

## サンプルデータについて

- 最初の35手は手で決めた定跡手順、36手目以降は簡易的な探索プログラムの自己対局です。
- 評価値・候補手・読み筋も同じ簡易探索の結果で、水匠の出力ではありません。数値の精度に意味はなく、盤面と数字が食い違わないことだけを目的にしています。
- 1手詰め・3手詰めの表示は、cshogi の詰み探索で確認できたものだけです。
- 対局者名は架空です。
