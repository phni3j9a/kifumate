# kifumate UIモック

UI/UXを決めるための検討用モックです。決まったものは実装見本として使います。
特定のアプリ開発技術には依存しない、素のHTML/CSS/JavaScriptで作っています。

## いまあるもの

| ファイル | 内容 |
| --- | --- |
| `src/app-pop.html` と `src/app/` | アプリ全体のモック（ポップ案）。オンボーディング・棋譜一覧・取り込み・対局画面（未解析／解析中／解析済み・分岐）・AI解説・戦績・設定を通して操作できる。**いまの本線** |
| `src/analysis-pop.html` | 解析画面だけのポップ案。解析画面の検討が一段落した時点の記録（以後の変更は `app-pop` 側に入れる） |
| `src/analysis-variants.html` | 解析画面のデザイン3案（A 和モダン／B 明るいミニマル／C ポップ）の比較ページ。方向性を選ぶための記録 |
| `data/sample-game.json` | サンプル棋譜1局目と各局面の解析データ（あなたが先手で勝ち） |
| `data/sample-game-2.json` | サンプル棋譜2局目（あなたが後手で負け）。取り込みの流れで使う |
| `data/*.raw.json`、`data/sample-game-2.meta.json` | 解析の生データと、2局目の対局者名・日付などの上書き。`rebuild` で JSON を作り直すときに使う |
| `tools/gen_sample_game.py` | サンプルデータの生成スクリプト（Python + cshogi） |
| `assets/mascot/*.webp` | モックで使うマスコット画像（素材集から、使う分だけを画面の大きさに合わせて小さくしたもの） |
| `tools/make_mascot.py` | 素材集から `assets/mascot` を作り直す。どの絵をどこに使うかの対応もここにある |
| `tools/build.py` | `src` に部品・データ・画像を埋め込んで `dist` に書き出す |
| `dist/*.standalone.html` | そのままブラウザで開ける単体ファイル |
| `dist/*.html` | 公開用（外枠なし。公開時に `<html>` などが付く） |

`src/app/` の中身：

| ファイル | 内容 |
| --- | --- |
| `app.css` | スタイル一式（色・形の決まりは先頭の `.vc` にある） |
| `data.js` | 画面に出す架空のデータ（棋譜一覧、利用状況、学習プロフィール、戦法と囲いの一覧） |
| `shogi.js` | 局面の読み込み、合法手、駒を動かす処理、指し手の表記、KIFの書き出し |
| `core.js` | 画面の切り替え、シート、確認ダイアログ |
| `game.js` | 対局画面（盤・形勢グラフ・候補手・解析の進行・分岐） |
| `ai.js` | AI解説とチャット（文章は解析データから組み立てたサンプル） |
| `screens.js` | 棋譜一覧・絞り込み・取り込み・戦績・設定とその下の画面 |
| `onboarding.js` | 初回起動のオンボーディング（7場面） |
| `boot.js` | 状態（初回起動／利用中）とプランの切り替え、説明欄からの画面ジャンプ、起動 |

## 決まっていること

- **解析エンジンと評価関数の名前は、アプリの画面や説明文に出さない。** 評価関数は、その名前（または、そこから追加学習したものであること）をサービス上で明記すると利用料がかかり、明記しなければかからない（2026年9月に権利者へ確認）。エンジン本体はGPLで、サーバー上で動かして結果だけをアプリに返す使い方はその範囲内。名前を出さない方針にしたので、「このアプリについて」やライセンス表示にも載せない。ストアの掲載文や公式サイトも「サービス上」に当たりうるので、同じ扱いにしておくのが安全。AI解説の文章にも名前が出ないよう、言語モデルへの指示では「解析エンジン」「解析結果」と呼び、名前を渡さない。
- 製品のUI・説明文に、他社の対局サービス名を使わない（仕様書より）。

## 見かた

`dist/app-pop.standalone.html` をブラウザで開きます。スマホで開くと、枠なしで画面いっぱいに表示されます。
右上の「無料／有料」でプランごとの見え方を切り替えられ、説明欄のボタンから各画面を直接開けます。
「状態」を「初回起動」にすると、何も保存されていない状態からオンボーディングが始まります（URLの末尾に `#first-run` を付けて開いても同じです）。

## マスコット

- 素材集（ミーアキャット、1024px のPNG 52点と見本帳）そのものは、このリポジトリには入れていません。入っているのは、モックで使う21点を小さくした `assets/mascot/*.webp` だけです。
- 使っている場所：オンボーディング（7場面）、AIコーチの丸いアイコン（聞いている／考え中／説明中／ひらめいた／やったね、を場面で切り替え）、空の一覧、検索結果なし、読み取れない棋譜、重複、バックアップ、最初の解析ができたとき、アプリアイコン。
- 解析画面の盤・グラフ・候補手のまわりには置いていません（情報の密度が高いため）。
- 素材集にあってまだ使っていないもの：通信切れ・上限到達の絵（その画面を作るときに使う）、局面の解説カット、学習の節目、横長バナー、端からのぞく絵、小物。

## 作り直しかた

```
python3 mock/tools/build.py
```

サンプルデータから作り直す場合は、先に `mock/tools/gen_sample_game.py` で自己対局・解析・検証を行います（`pip install cshogi` が必要。手順はスクリプト冒頭の「使い方」を参照）。時間制限つきの探索なので、解析をやり直すと完全に同じデータにはなりません。`rebuild` は保存済みの生データから作るので、同じ結果になります。

## サンプルデータについて

- 2局とも、最初の35手は手で決めた定跡手順、36手目以降は簡易的な探索プログラムの自己対局です。
- 評価値・候補手・読み筋も同じ簡易探索の結果で、実際の解析エンジンの出力ではありません。数値の精度に意味はなく、盤面と数字が食い違わないことだけを目的にしています。
- 1手詰め・3手詰めの表示は、cshogi の詰み探索で確認できたものだけです。
- 対局者名、棋譜一覧のほかの対局、戦績、利用状況、価格は架空です。

## モックの制限

- 中まで開ける対局は、サンプルデータのある2局だけです。ほかは一覧のカードだけで、カードの小さなグラフも作り物です。
- 分岐中の評価値（有料プランのリアルタイム解析）は、保存済みの候補手の読み筋に沿って進めた局面でだけ出ます。
- 解析の進行は数秒で終わる演出です。実際はサーバーで1〜3分ほどかかる見込みです。
- AI解説の文章は、解析データから機械的に組み立てたサンプルです。
