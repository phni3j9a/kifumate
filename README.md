# kifumate

将棋の棋譜を記録・解析し、対局の振り返りを支援するアプリです。

- [製品要求仕様](kifumate-spec.md)
- [UIモックと決定事項](mock/README.md)
- [アプリ：開発・実行・現状](app/README.md)
- [解析サーバー：API・開発・デプロイ](server/README.md)
- [stagingの実測と費用見積もり](server/docs/measurement.md)

現状：Expoアプリの骨組みとオフラインの棋譜管理（KIF取り込み・名前照合・検索・お気に入り・盤の再生・合法手の分岐・書き出し）を実装しました。保存にはUUIDと移行機構付きの端末内SQLiteを使用します。Webと接続Android実機で主要フローを確認済みです。

全局解析サーバーはstagingで通常・精密の解析を検証済みですが、アプリへの接続はまだありません。戦績集計・戦法と囲いの分類・一括バックアップ・購入権利検証・分岐中の解析・AIコーチは未実装です。公開前には配布ビルドでの端末確認、端末認証・不正利用対策と本番向け負荷検証が必要です。
