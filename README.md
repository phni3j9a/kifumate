# kifumate

将棋の棋譜を記録・解析し、対局の振り返りを支援するアプリです。

- [製品要求仕様](kifumate-spec.md)
- [UIモックと決定事項](mock/README.md)
- [アプリ：開発・実行・現状](app/README.md)
- [解析サーバー：API・開発・デプロイ](server/README.md)
- [stagingの実測と費用見積もり](server/docs/measurement.md)

現状：Expo SDK 58 のアプリで、KIF取り込み・名前照合・検索・お気に入り・再生・合法分岐・書き出し、戦績集計・戦法と囲いの分類、全局解析（ふつう／精密）、分岐中の解析、AIコーチ・学習プロフィール、招待コードによる有料機能の有効化を実装しています。SQLiteで棋譜・解析・解説を端末内に保存します。リリースは本番APIに接続し、開発はstagingに分離しています。

Androidは自分・知人向けの署名付きAPK（arm64-v8a専用）を、EASを使わずリポジトリのスクリプト（`npm run build:android`）で作成します。配布中は0.1.0／更新番号19（EASで作成）で、以後は版から算出した番号（0.1.0→1000）で同じ鍵のまま上書き更新できます。32bit ARM・x86／x86_64端末は対象外です。配布・更新・署名鍵の扱いは[アプリのビルド手順](app/README.md#androidの配布apkビルド)を参照してください。APKや鍵は公開リポジトリ／GitHub Releasesへ置きません。ストア公開・購入連携はまだ行いません。

一括バックアップと復元・同期・オンボーディング・見本の対局・RevenueCatによる課金は未実装です。アンインストールすると端末のデータが失われるため、重要な棋譜はKIFで保管してください。iPhoneの実機確認、端末認証（Play Integrity / App Attest）、多数の利用者向けの負荷検証も残っています。
