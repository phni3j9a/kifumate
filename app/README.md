# kifumate アプリ

Expo SDK **58.0.25** / React Native / TypeScript / expo-router で作った、端末内で動く棋譜管理アプリです。画面と固定ライト配色は [UIモック](../mock/README.md) のポップ案に準拠しています。

見た目の決まりと部品はモックの `mock/src/app/app.css`（`.vc`）に1対1で対応させています。画面側で色や形を直書きせず、次を使います。

- `src/components/theme.ts`：色・書体（Zen Maru Gothic 500/700/900）・線・角丸・影のトークンと `font(太さ, 大きさ, 行の高さ, 色)`。
- `src/components/ui.tsx`：ボタン・チップ・切り替え・カード・行・入力欄・空の状態・お知らせカードなど（かっこ内にモックのクラス名）。
- `src/components/overlay.tsx`：知らせ（`toast`）・シート（`Sheet` / `MenuRow`）・確認ダイアログ（`ask`）。モックの `core.js` と同じく、それぞれ1種類。
- `src/components/icons.tsx`：モックの SVG アイコン。`board.tsx`・`graph.tsx`：盤・駒・形勢グラフ。

## 開発・実行

Node.js **22.23以降**（テストで `node:sqlite` を使用）、npm、Android の確認には Expo Go の SDK 58 対応版が必要です。

```sh
cd app
npm ci
npm run web       # Web。端末内DBはブラウザの同じオリジンに保存
npm start         # QRコードから Expo Go で開く
npm run android   # 接続したAndroid / 使用可能なエミュレータで開く
```

USB 接続の実機を使う場合：

```sh
adb devices
adb reverse tcp:8081 tcp:8081
npx expo start --localhost
# 別のターミナルで
adb shell am start -a android.intent.action.VIEW -d exp://127.0.0.1:8081 host.exp.exponent
```

開発サーバーの停止は `Ctrl+C`。Web は動作確認用で、インストール可能なオフラインPWAではありません。Web を再読み込みするには開発サーバーまたは配信先への接続が必要です。Android の保存データの閲覧・操作には解析サーバーも外部通信も不要です。

Web の本番用バンドル：`npx expo export --platform web`。配信時は SPA のルートフォールバック、WASM の MIME `application/wasm`、`Cross-Origin-Embedder-Policy: credentialless` と `Cross-Origin-Opener-Policy: same-origin` を設定してください。expo-sqlite の Web 対応は実験的です。

## いま使えること

- 棋譜・戦績・設定の3タブ（戦績は空画面）と、取り込み・対局・対局情報・対局者名・このアプリについて・ライセンス。KIFの書き出し・絞り込み・結果の修正・「…」メニューはシート、削除は確認ダイアログ。
- 取り込みは「テキスト／ファイル」の切り替え。UTF-8 / Shift_JIS のKIFを貼り付け・入力・ファイル選択すると自動で読み取り、日付・対局者・結果、先手か後手か、重複を保存前に表示。2MB・10000手を上限に検証し、読み取れない理由を表示。
- 開始局面のSFEN（手番・持ち駒を含む）と本譜のUSI指し手の完全一致で重複防止。名前・日付・コメント・消費時間・終局理由・入力内の変化は重複判定に使わない。ハッシュではなく正規化した値を比較するため衝突はない。
- 対局者名は1件ずつ追加し、× で外す（「元に戻す」付きの知らせ）。複数登録でき、NFKC正規化・前後の空白除去・大小文字の同一視で照合。両側に一致する場合は未指定。登録名の変更で自動判定の棋譜だけ再照合し、手動修正は維持。
- 勝ち・負け・引き分け・わからない。未指定・他人の棋譜は戦績対象外。終局理由がない場合は推測せず、対局情報で指定できる。対局情報の「あなたはどちら」は押した時点で保存し、結果は「修正」からシートで直す。
- 棋譜の削除（「…」メニュー → 確認ダイアログ）。削除後は一覧に戻り「削除しました」を出す。`games.id` を参照する後続のテーブルは `ON DELETE CASCADE` で一緒に消える。
- 対局者名・日付の検索、自分／他人・先後・勝敗・お気に入りの絞り込み。現時点では全件未解析。
- 盤・左右の駒台・上下の対局者名、後手側からの表示、盤の反転（「…」メニュー）、手順一覧・1手／最初／最後への移動。
- 任意の局面で盤上の駒・持ち駒を動かすと分岐が始まる（本譜の次の手と同じなら本譜を進める）。成・不成は盤上の吹き出しで選び、強制成・二歩・王手放置・打ち歩詰めも判定。分岐内の戻る／進むと、戻って別の手を指す操作に対応。本譜・戦績に書き込まず、画面を閉じると分岐は破棄。
- 本譜のKIFをコピー・保存／共有（Web はダウンロード）。UTF-8 の `.kifu` を出力。元の開始局面・名前・日付・コメント・消費時間・入力内の変化を保持。アプリ内の結果修正・一時分岐は含めない。
- 評価値グラフ・候補手は未解析表示だけ。「解析する」は無効のボタンとして形だけ置いている。架空の評価値や解析済みの演出は入れていない。

## 保存と拡張方針

`src/storage/schema.ts` の順番付きマイグレーションを `PRAGMA user_version` で管理し、起動時にトランザクション内で適用します。失敗時はロールバックし、新しいDBを古いアプリで開いた場合は更新を案内します。データの自動初期化はしません。

- `games`：UUID、開始局面＋本譜の一意キー、正規化KIF、検索用メタデータ、先後・結果、自動／手動の区別、お気に入り、作成／更新日時。
- `aliases`：UUID、表示名、一意の正規化名、登録日時。
- UUID は端末内で生成。SQL はユーザー入力を文字列連結せずバインドする。
- 解析結果・戦法／囲い・AI解説は、今後の移行で `games.id` を参照する別テーブルとして追加できる。安定ID・更新日時と、UIに依存しないKIFを保存する構造にしており、バックアップ／同期の処理は今回入れていない。
- 外部入力用の2MB上限と保存済みKIFの読み込みを分離。CRLF化・ヘッダー追加で大きくなった保存済み棋譜も開けるようにし、保存前に正規化KIFの再解析を完了させる。保存できない場合はINSERTせず、既存棋譜を変更しない。
- ネイティブのファイル選択は `File.pickFileAsync`。選択ファイルの権限を受け取り、他機能の共有キャッシュのパスには依存しない。Web は `expo-document-picker` の `File` を読む。

## 依存ライブラリの選定

将棋ルールを独自実装し直さず、**[tsshogi 2.3.4](https://github.com/sunfish-shogi/tsshogi)** を採用しました。MIT、TypeScript製、KIF・任意開始局面・駒落ち・変化・合法手（打ち歩詰めを含む）・書き出しが一体で提供されるためです。2026-11-17 に npm の版・LICENSE と GitHub を確認：npm 最終更新 2026-06-07、リポジトリ最終push 2026-11-01、アーカイブされていません。読み込みはライブラリの許容的なパーサーだけに任せず、手数の連続性・盤面図の全9段と各マスの構文・入力順の分岐局面における駒種と成／不成／打・全ノードの合法性を追加検査しています。

文字コードは **[encoding-japanese 2.5.0](https://github.com/polygonplanet/encoding.js)**（MIT、npm 最終更新 2026-11-02）。ネイティブの文字デコーダーの対応範囲に依存せず、同じコードで Shift_JIS と UTF-8 を処理できるためです。両ライセンス原文は `src/assets/*-LICENSE.txt`、著作権表示とMIT全文は設定内のライセンス画面にもあります。

見た目をモックに合わせるため、盤・駒・アイコン・グラフをモックのSVGどおりに描く **react-native-svg 15.16.0**（MIT、Expo SDK 58 の対応版・Expo Go 同梱）と、モックの書体 **@expo-google-fonts/zen-maru-gothic 0.4.2**（Zen Maru Gothic、OFL-1.1。500/700/900 だけ読み込む）を使います。フォントのライセンス原文は `src/assets/zen-maru-gothic-OFL.txt` とライセンス画面にあります。

これ以外の実行依存は Expo の標準機能・Router とその必須パッケージ・アイコンです。別の状態管理・DBラッパー・UIキットは追加していません。マスコットはこのリポジトリの `mock/assets/mascot/` から使用分のみ取り込んでいます。

## 検証

```sh
npm run check    # 単体テスト・禁止名称検査・型検査・lint
npx playwright install chromium  # 初回のみ。sudoは不要
npm run test:web # Metroを起動し、Chromiumで主要フローを自動確認
npx expo export --platform web
node scripts/check-product-names.mjs dist  # 配布バンドル・アセットにも禁止名称がないか検査
```

- 単体：KIFの全角／半角座標・同・成・コメント・消費時間・CRLF・BOM・ASCIIヘッダー、駒落ち、盤面図、入力内の変化、UTF-8 / Shift_JIS、エラー、重複、名前照合、終局理由、合法分岐、書き出し往復、移行の再実行／未来版／ロールバック。
- Web E2E：対局者名の追加・外す・元に戻す→貼り付けで自動の読み取り→保存→再起動後の永続化→検索／お気に入り／検索結果なし→再生→本譜と同じ手は本譜を進める→駒を動かして分岐→本譜復帰→「…」メニューからKIFダウンロードと再解析→対局情報（先後の即時保存・結果の修正）→名前の再照合でも手動修正を維持→Shift_JISファイルの重複を保存前に表示→通信を切った状態での再生→削除の確認（やめる／削除する）と「削除しました」。
- `scripts/check-product-names.mjs` は製品ソース・アセットと指定したバンドルを走査し、使用しない固有名称が混入したら失敗する。検査コード・テスト・開発文書自体は製品表示の対象外。利用者の入力・取り込み済み棋譜を改変するものではない。
- スクリーンショット：`.local/screenshots/web/` と `.local/screenshots/android/`（gitignore 済み）。

## 範囲外・注意

解析サーバー連携、戦績集計、戦法／囲い分類、AIコーチ、課金、一括バックアップ・復元、同期、オンボーディングは未実装です。モックにあるこれらの入口（AIに聞く、精密タブ、解析回数、プラン、学習プロフィール、バックアップ、見本の対局、戦法と囲いの絞り込み）は、次の段階で機能と一緒に追加します。分岐は一時的な検討用で保存しません。KIF以外の棋譜形式、UTF-16・EUC-JP は受け付けません。未対応の終局理由や不正な指し手はエラーにし、勝敗の根拠がない棋譜は「わからない」にします。

Web はブラウザのサイトデータ削除・プライベートブラウズ、ネイティブはアプリデータ削除／アンインストールで棋譜が失われます。一括バックアップが入るまでは大切な棋譜をKIFで保管してください。

`npm audit` では Expo の開発・ビルド用 `@expo/fingerprint` 経由の `minimatch` に moderate（ReDoS）が残ります。SDKを旧版へ戻す自動修正は適用していません。アプリが棋譜処理に使う依存ではありませんが、公開前に上流の修正を追ってください。
